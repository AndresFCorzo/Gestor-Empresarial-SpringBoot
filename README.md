# 🏢 GESTOR EMPRESARIAL INTEGRADO - SPRING BOOT

## Descripción
Sistema de gestión contable y administrativa desarrollado con Spring Boot.

## Tecnologías
- Java 11
- Spring Boot 2.7.0
- Spring Data JPA
- Spring Security
- MySQL 8.0
- Thymeleaf
- Bootstrap 5

## Requisitos
- JDK 11+
- MySQL 8.0+
- Maven 3.6+
